Windows quick setup

Requires Python 3.10–3.12. The first Local-mode run downloads the AI model.

# navigate to the project folder
cd BG-Remove

# create a virtual environment and install
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# launch the desktop app
python app.py

PowerShell may ask you to allow local scripts with Set-ExecutionPolicy RemoteSigned -Scope CurrentUser.

HELP AND PRIVACY

Frequently asked questions

Is my image uploaded anywhere?

In browser mode the image you choose goes directly from your browser to remove.bg using your key. This site has no server and does not receive or store it. remove.bg handles it under its own terms. The desktop app's Local mode processes images entirely on your computer.

Do I need a paid remove.bg account?

You need a remove.bg account and API key. Limited free previews are available, and your plan determines credits and output resolution. Create or manage a key at remove.bg.

Is my API key saved?

No. In browser mode the key stays in this tab's memory, is sent only to remove.bg, and disappears when you reload or close the page. The desktop app can optionally remember it locally.

Which files can I use?

Browser mode accepts PNG, JPG and WEBP files up to 20 MB. The desktop app additionally accepts BMP and GIF files and has no browser upload step.

Can I remove backgrounds completely offline?

Yes. Install the desktop app and choose Local mode. rembg's U²-Net model runs on your machine. The first run downloads the model; later runs can work without an internet connection.
