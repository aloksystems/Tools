About Global Chat

Global Chat is a real-time chat app built on Firebase. Messages sync instantly, and the last 50 messages of a chat are loaded when you open it.

  • Long-press or right-click a message for actions
  • Reply, react, edit your own messages and delete
  • Presence and typing indicators
  • Light and dark themes that match the rest of the tools
