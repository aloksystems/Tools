    HELP AND PRIVACY

    Frequently asked questions

    Are my images uploaded to a server?

    No. Every image is read and compressed inside your browser using the canvas element. Nothing is uploaded or stored online.

    Which formats can I compress?

    You can add JPG, PNG, WebP, GIF, and BMP images that the browser can open. The compressed result can be saved as JPG, WebP, or PNG.

    Why does a PNG file not get smaller?

    PNG is lossless, so the quality slider does not apply. Enabling Resize large images or choosing JPG or WebP will usually reduce the file size.

    Does compressing reduce image dimensions?

    Only when Resize large images is enabled and a side is larger than the maximum dimension. Otherwise the original pixel dimensions are kept.
