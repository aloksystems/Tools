HELP AND PRIVACY

Frequently asked questions

Are my images uploaded anywhere?

No. Resizing happens in your browser using the canvas element. Your image never leaves this device and no copy is stored on a server.

Which formats are supported?

You can upload JPG, PNG, and WebP images. The resized file can be saved as JPG, PNG, or WebP.

How does lock aspect ratio work?

When enabled, changing the width automatically updates the height to keep the original proportions, and the other way around. Turn it off to set both values independently.

Is there a size limit?

Each side can be up to 8,000 pixels and the output is limited to 50 megapixels so the browser stays responsive.
