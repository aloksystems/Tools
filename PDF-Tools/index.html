Help and privacy

Frequently asked questions

Are my PDFs uploaded to a server?

No. Each tool processes your file inside this browser. The document is not sent to a server and no copy is stored online.

Is PDF Tools free to use?

Yes. Every tool is free, with no account, watermark, or export limit.

Do I need to install anything?

No. Open a modern browser such as Chrome, Edge, Firefox, or Safari and use the tools directly from this page.

Which tools are included?

Merge, split, crop, rotate, reorder, extract or delete pages, compress, convert to and from images, extract text, edit metadata, protect, unlock, sign, watermark, add page numbers, and scan to PDF.

Why did a tool fail on my PDF?

Password-protected, damaged, or unusually large PDFs can exceed what the browser can process. Try unlocking the file first, or use a smaller document.
