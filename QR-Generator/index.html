HELP AND SCANNING

Frequently asked questions

Are the QR codes free and private?

Yes. Every QR code is generated locally in your browser with an open-source JavaScript library. Nothing is uploaded, tracked, or stored.

Which content types can I create?

The generator supports website URLs, plain text, Wi-Fi network details, email messages, SMS messages, and vCard contact cards. Each type uses the format scanners expect.

Why will my QR code not scan?

Use a dark foreground on a light background with a contrast ratio of at least 4.5:1, keep the built-in quiet zone, and print or display the code large enough. Inverted colours may not work in every scanner.

Does a Wi-Fi QR code reveal the password?

Yes. The password is encoded inside the QR code so compatible devices can join the network. Share the code only with people you trust, and change the password if it is posted publicly.

Do the QR codes expire?

No. These are static QR codes, so the encoded content is fixed. There is no redirect service, expiry date, or scan tracking.
