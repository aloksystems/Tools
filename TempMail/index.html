HELP AND LIMITS

Frequently asked questions

Is this temporary email private?

The address is not linked to your real identity, and this page stores nothing. Messages are handled by the temporary email provider that creates the inbox, so treat the address as public and avoid using it for sensitive accounts.

How long does the inbox last?

The session lives only in this tab. Reloading starts a new address, and the provider controls how long its server keeps the old inbox.

What happens if both providers are unavailable?

A placeholder address is shown for copying only and cannot receive messages. Generate again later to retry Guerrilla Mail and Mail.tm.

How does the OTP watcher work?

It checks the inbox at your chosen interval until it finds a 4–8 digit code or reaches the timeout. The countdown appears beside Refresh inbox. All checks stop when a code is found, you press Stop waiting, or time runs out.

Are messages or credentials stored?

No. This page writes no inbox, message, or credential to local storage and has no server of its own. Closing or reloading the tab ends the session.
