    Quick setup

    1. Install Python 3.9+ and FFmpeg, then add FFmpeg’s bin folder to PATH.
    2. In the Yt_Downloader folder, run:
    # install Python dependencies pip install yt-dlp customtkinter Pillow # launch the desktop app python main.py

    FFmpeg builds are available from gyan.dev. The app runs on Windows, macOS, and Linux.

    HELP AND EXPECTATIONS

    Frequently asked questions

    Can I download YouTube videos from this page?

    No. This page checks links and plans settings. The download itself runs in the Python desktop app, because browsers cannot run yt-dlp or FFmpeg.

    Do I need to start a web server?

    No. main.py is a desktop window, not a web server or API. There is no localhost endpoint to start.

    What formats and qualities does the app support?

    MP4 video with best video and audio merged, or MP3 audio at 192 kbps. Resolution caps range from 4320p down to 144p, and the best available quality is used by default.

    Does it support playlists and subtitles?

    Yes. Playlist downloading is on by default. English subtitles, including auto-generated ones, can be enabled, and thumbnails can be saved and embedded in MP4 videos.

    Where are downloaded files saved?

    By default the app saves to a YouTube folder inside your Downloads directory. You can choose any output folder before starting.
