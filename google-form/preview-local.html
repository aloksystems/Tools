    How to use FormForge

    ChatGPT writes the spec · FormForge builds the form.

    1. Tell ChatGPT what form you want (purpose, audience, questions, required fields).
    2. Ask ChatGPT to return JSON following the FormForge schema (use the prompt below).
    3. Copy the JSON without surrounding Markdown code fences.
    4. Paste it into FormForge and click Validate JSON.
    5. Review the preview and edit anything.
    6. Click Generate Google Form and copy your three links.

    FormForge · Google Apps Script · Forms + Sheets are created in your own Google account. No external database.

    Help & authorization

    FormForge creates real Google Forms + linked response Sheets in your Google account.

    On first use Google will ask you to authorize these scopes:

    • forms — create & configure forms
    • spreadsheets — create response spreadsheets
    • drive.file — access files the app creates
    • userinfo.email — show your account in the header

    Resources are owned by the account that runs the Web App (see README for Execute-as settings). If you see an authorization error, re-open the deployment URL while signed in and accept the consent screen.

    Tips: paste JSON without Markdown code fences (no ```json). Use Validate JSON before generating. Generation is idempotent — repeated clicks with the same draft won't duplicate forms.
