    How it works

    ChatGPT writes the spec · FormForge builds the form.

    1. Tell ChatGPT the form you need — purpose, audience, questions and which fields are required.
    2. Ask it to answer with JSON using the prompt below, without Markdown fences.
    3. Paste the JSON, click Validate JSON, and fix anything flagged in the preview.
    4. Click Generate Google Form and copy the respondent link, editor link and response sheet.

    Frequently asked questions

    Where are the Form and response Sheet created?

    They are created in the Google account used to authorize and run this web app. Ownership depends on the Apps Script deployment’s “Execute as” setting.

    Does FormForge store my JSON or generated forms?

    FormForge has no external database. The JSON is sent to the Apps Script backend only for validation and to create the resources you requested. Generated Forms and Sheets are saved in Google Drive.

    Can I inspect the form before it is created?

    Yes. Validate the JSON, review the editable preview, and make changes before selecting “Generate Google Form”.

    Why might Google ask me to authorize access?

    The app needs permission to create Forms and spreadsheets. Review the Google consent screen and grant access only if you want to use these features.

    Help & authorization

    FormForge creates a real Google Form plus a linked response spreadsheet in your Google account.

    On first use Google will ask you to authorize these scopes:

    • forms — create and configure forms
    • spreadsheets — create response spreadsheets
    • drive.file — access files the app creates
    • userinfo.email — show your account in the app bar

    Resources are owned by the account that runs the Web App (see the README for Execute-as settings). If you see an authorization error, re-open the deployment URL while signed in and accept the consent screen.

    Shortcuts: Ctrl/Cmd + Enter validates the JSON. Esc closes this dialog.

    Tips: paste JSON without Markdown fences (no ```json). Validate before generating. Generation is idempotent — repeated clicks with the same draft won’t duplicate forms.
